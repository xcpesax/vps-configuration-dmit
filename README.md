## 1核1G VPS 适合哪些用途？

1GB 内存的 VPS 可以完成不少基础任务，但需要控制软件规模。

比较适合：

* 个人博客、小型企业展示站
* 静态网站托管
* WordPress 轻量安装
* 学习 Linux 命令和服务器管理
* Git 私有仓库
* 小型 API 服务
* 定时任务脚本
* 开发测试环境
* 低访问量应用

不太适合：

* 高访问量电商网站
* 大型数据库应用
* 多服务 Docker 集群
* 视频处理
* 大规模爬虫任务
* 需要大量缓存的程序

实际使用中，1GB 内存并不等于“只能运行 1GB 的程序”。Linux 本身占用较少资源，但 Web 服务、数据库、运行环境都会消耗内存。

例如：

* Nginx + 静态页面：压力较小
* Nginx + PHP + 小型 MySQL：可以运行，但需要优化
* Node.js 应用 + 数据库 + 多插件：可能需要升级配置

因此，购买 1核1G VPS 前，最好先确定你的服务类型，而不是只比较价格。
